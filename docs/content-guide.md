# 内容编辑指南

## 第一次使用

1. 打开 <https://app.pagescms.org/>。
2. 使用保存本项目的 GitHub 账号登录。
3. 选择 `personal-homepage` 仓库。
4. 左侧会出现“个人空间设置、项目、校园手记、随笔、资料库”。

## 新增一篇内容

1. 进入对应栏目并选择“新建”。
2. 填写标题、摘要、正文、分类和日期。
3. `网址标识` 使用小写英文、数字和连字符，例如 `my-first-note`。
4. 编辑过程中先关闭 `公开发布`，内容不会显示在网站上。
5. 准备完成后打开 `公开发布` 并保存。

保存后 GitHub 会自动检查并更新网站，通常需要一到几分钟。检查失败时，已经上线的网站不会被替换。

## 图片

在头像、封面或正文的图片按钮中上传。系统会把图片放进 `public/media/`，并自动写入可访问地址。

建议：

- 照片使用 WebP 或 JPG
- 单张图片尽量控制在 1 MB 内
- 不上传包含学号、证件、宿舍门牌或其他私人信息的图片
- 发布校园资料前检查图片是否包含其他人的面部

## 资料有效性

资料条目必须填写“最后核验”日期。链接或规则变化后，应同步更新日期；无法确认时将 `公开发布` 关闭。

## 修改网络 ID

进入“个人空间设置”，修改“网络 ID”和头像即可。网站没有真实姓名字段，不需要为了隐藏姓名再做额外设置。
