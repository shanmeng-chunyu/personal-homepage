# 内容编辑指南

## 第一次使用

1. 打开 <https://app.pagescms.org/>。
2. 使用保存本项目的 GitHub 账号登录。
3. 选择 `personal-homepage` 仓库。
4. 左侧会出现“个人空间设置、项目、校园手记、随笔、资料库”。

## 新增一篇内容

1. 进入对应栏目并选择“新建”。
2. 填写标题、摘要、正文、分类和日期。
3. 标题可以直接使用中文；`网址标识` 仅用于生成 JSON 文件名和网址，使用小写英文、数字和连字符，例如 `my-first-note`。
4. 编辑过程中先关闭 `公开发布`，内容不会显示在网站上。
5. 准备完成后打开 `公开发布` 并保存。

保存后 GitHub 会自动检查并更新网站，通常需要一到几分钟。检查失败时，已经上线的网站不会被替换。

## 图片

在头像、封面或正文的图片按钮中上传。系统会把图片放进 `public/media/`，并自动写入可访问地址。

建议：

- 照片使用 WebP 或 JPG
- 单张图片尽量控制在 1 MB 内
- 不上传包含学号、证件、宿舍门牌或其他私人信息的图片
- 发布校园资料前检查图片是否包含其他人的面部

## 资料有效性

资料条目必须填写“最后核验”日期。链接或规则变化后，应同步更新日期；无法确认时将 `公开发布` 关闭。

资料库支持两种打开方式：

- `外部链接`：填写完整网址，卡片会在新窗口打开该网站。
- `站内文章`：填写站内正文，卡片会进入与随笔、校园手记一致的阅读页。

两种方式只填写对应的一项：外部资源留空“站内正文”，站内文章留空“外部链接”。准备好之前先关闭 `公开发布`；发布时系统会检查外部资源是否有网址、站内文章是否有正文。

## 修改个人信息与联系方式

进入“个人空间设置”，可以修改网络 ID、头像、首页介绍、栏目页标题与说明、GitHub、B站主页和 QQ。

- B站主页填写以 `https://` 开头的完整链接
- “项目页标题/说明”“校园手记页标题/说明”“随笔页标题/说明”“资料库页标题/说明”会显示在对应栏目标题下方，可以直接写中文
- QQ 只填写号码
- B站和 QQ 留空时不会在网站上显示
- 填写 QQ 意味着同意将该号码公开展示

同一页还可以填写“首页 B站视频 1”和“首页 B站视频 2”：

- 支持 `bilibili.com/video/BV...` 完整链接或 `b23.tv` 分享短链接
- 网站发布时会自动读取视频标题和封面，不需要手动上传
- 首页最多展示两个视频，卡片封面固定为 4:3
- 删除某个链接后，对应视频卡片会自动隐藏
- B站接口暂时不可用时不会阻止网站发布，卡片会使用安全占位

网站没有真实姓名字段，不需要为了隐藏姓名再做额外设置。

## 受密码保护的长篇

长篇内容不使用 Pages CMS，因为仓库是公开的，提交普通 JSON 会泄露正文。新增或修改时：

1. 在本地创建 `private-content/fiction/`，每篇文章准备一个元数据 JSON 和一个正文 Markdown，例如 `chapter-one.json` 与 `chapter-one.md`。
2. 将 `examples/fiction-entry.example.json` 复制为新的 JSON 文件，填写 `slug`、标题、摘要、`bodyFile`、发布日期、更新时间和章节顺序。`bodyFile` 只能指向 `private-content/fiction/` 内的 `.md` 文件，不要使用绝对路径或 `../`。
3. 将 `examples/fiction-chapter.example.md` 复制为正文 Markdown，直接按普通文档写正文，可以自然换行，不需要写 JSON 转义符。
4. 在不会提交的 `.env.local` 中设置 `FICTION_PASSWORD=你的4位数字密码`，例如 `FICTION_PASSWORD="4827"`。
5. 运行 `npm run fiction:encrypt`，确认只生成或修改 `public/protected/fiction/` 下的密文文件。
6. 运行 `npm run check` 和带仓库子路径的 Pages 构建，再提交密文和代码。

密码不会写入密文或构建配置，忘记后无法从仓库恢复。更换密码时，保留本地明文草稿并重新运行加密命令。不要在正文中引用需要保密的 `public/` 图片，因为静态图片地址不受密码保护。
长篇密码按设计为 4 位数字，安全性较低，不适合保护高度敏感的信息。
